Статистика Refrain

Страница скрытая и без ссылок с сайта. Данные трафика GitHub отдаёт только тем, у кого есть доступ с правом записи к репозиторию, поэтому без токена владельца здесь ничего не видно. Токен уходит только на api.github.com и нигде не сохраняется: он живёт в памяти страницы, после перезагрузки его нужно ввести снова.

Владелец и репозитории

Как создать токен
  1. Открой GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner — TryserPy. Срок действия поставь небольшой (например, 30 дней).
  3. Repository access — Only select repositories: только TryserPy/Mnema и TryserPy/Mnema-site.
  4. Repository permissions — всё только на чтение:
    • Administration: Read-only — именно это право GitHub требует для данных трафика (просмотры, клоны, источники, страницы);
    • Contents: Read-only — выпуски и файлы;
    • Metadata: Read-only — звёзды, форки, наблюдатели (ставится само).
  5. Нажми Generate token, скопируй токен (он показывается один раз) и вставь сюда. Токен без записи ничего не может изменить. Менеджер паролей лучше не использовать: страница ничего не запоминает.

Подойдёт и классический токен со scope public_repo, но он шире нужного — лучше fine-grained. Скачивания выпусков публичные и видны любому, а вот трафик — только владельцу.

Владелец и репозитории

Токен и ответы GitHub хранятся только в памяти страницы (ответы — несколько минут, чтобы не тратить лимит). Кнопка «Выйти» их стирает; перезагрузка тоже.
