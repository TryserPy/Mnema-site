# Мнема — сайт

Сайт приложения [Мнема](https://github.com/TryserPy/Mnema): что это, как работает, документация и ссылки на скачивание —
и сама **Мнема онлайн** (папка `app/`): веб-версия приложения для компьютера, планшета, Android, iPhone и iPad.
Сайт статический: чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Что на сайте

| Раздел | Адрес | Что внутри |
| --- | --- | --- |
| Главная | `#/` | карточки, история «фото → конспект → карточки → расписание», демо со смахиванием, карта знаний |
| Возможности | `#/features` | все функции с фильтром и поиском |
| Наука | `#/science` | кривая забывания, приёмы с исследованиями, мифы |
| Что нового | `#/updates` | история версий |
| Документация | `#/docs`, `#/docs/<раздел>` | инструкция, горячие клавиши, моды и стили |
| Скачать | `#/download` | Windows, Android и «В браузере», частые вопросы |
| Мнема онлайн | `app/` | веб-версия приложения (PWA): открывается в браузере, ставится как приложение, работает без интернета |

Страницы переключаются без перезагрузки (маршруты по `#`), поэтому сайт работает на любом статическом хостинге.
Тема (светлая/тёмная) запоминается; анимации отключаются при `prefers-reduced-motion`.

## Запуск

```bash
python3 -m http.server 8000   # или любой другой статический сервер
# открыть http://localhost:8000
```

## Устройство

- `index.html` — оболочка; выбирает интерфейс по ширине экрана.
- `css/style.css`, `js/app.js` — версия для компьютера и планшета.
- `css/mobile.css`, `js/mobile.js` — интерфейс для телефона: вкладки, экраны со стеком, шторки,
  жест «назад» (до 760 px по ширине или телефон в горизонтальном положении).
- `js/data.js` — все тексты: функции, версии, вопросы, документация (для телефона — `mobileData()`). **Правятся здесь.**

Версия и ссылки на установщики подтягиваются из [последнего выпуска](https://github.com/TryserPy/Mnema/releases/latest)
через GitHub API; если запрос не удался, остаются запасные значения (`FALLBACK_VER` в `js/app.js`).

### Новая версия приложения

0. Веб-версия обновляется отдельно (см. «Мнема онлайн»): сайт после выпуска ничего не пересобирает.
1. В `js/data.js` в начало списка `versions` добавить запись (она берётся из `CHANGELOG.md` приложения).
2. При необходимости обновить плашку «1.26 …» на главной (`js/app.js`, `pageHome`) и `FALLBACK_VER`.

## Мнема онлайн (`app/`)

Папка `app/` — готовая сборка веб-версии из репозитория [Mnema](https://github.com/TryserPy/Mnema) (`npm run build:web`).
**Руками её не правят**: её обновляет workflow `web.yml` в репозитории Mnema при каждом пуше в `main` (нужен секрет
`SITE_DEPLOY_TOKEN` с правом записи сюда). Вручную: в Mnema `npm ci && npm run build:web`, затем содержимое `dist-web/`
скопировать в `app/` (старое удалить).

- Пути в сборке относительные, поэтому она работает по любому адресу (`…/Mnema-site/app/`, свой домен).
- Приложение ставится как PWA и работает без интернета (service worker `app/sw.js` с областью `app/`; сайт его не затрагивает).
- Данные лежат в браузере (IndexedDB) на адресе, где открыта Мнема. Смена адреса (например, переезд на свой домен) = пустое
  хранилище: перенеси данные файлом-копией («Настройки → Данные»).
- Ссылки «Открыть онлайн» на сайте ведут на `app/` (`WEBAPP` в `js/app.js` и `js/mobile.js`).

## Публикация

GitHub Pages из ветки: *Settings → Pages → Deploy from a branch → `main` / `/ (root)`*.
Сайт обновляется сам после каждого мерджа в `main`.
